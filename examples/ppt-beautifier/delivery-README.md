# 可选 PPT 交付角色

这是登记目标 `binding.driver=ppt_delivery` 的固定领域实现，不是网关通用 DAG。制作角色 `ppt-beautifier` 的既有合同保留。交付角色自身的持久状态由网关和任务记录一起保存，网关后台调用 `advancePptDelivery` 推进；主会话不轮询。

配置结构见 `delivery-policy.example.json`。目标编号必须对应人工已登记目标，机器路径须按部署实际校验，不因拷贝示例自动存在。`workspaceRoot` 应在各执行宿主共同可读写的临时根内；PPT 公开目录位于制作角色允许目录内。此版本是同机文件交付角色，不能把本机绝对路径当作跨机共享文件系统。

`backupTargets` 可按 `project_script`、`ppt_production`、`independent_review` 指定预登记备用目标，`maxTargetSwitches` 限制整个交付父任务的切换次数。只在原子任务已确认 `failed` 后选择不同的备用目标，另建子任务并保存 `replacesJobRef`、原执行轮次、实际目标、原因与策略版本；父任务目标不变。受理未知、认证缺失、等待超时和失联都不能触发切换。同一目标修复继续原子任务并新增执行轮次；制作恢复同时使用新结果目录。样例备用编号只是配置示例，未登记时应移除该项，不自动创建目标或更改全局模型。

输入为 `projectDirectory`、`projectName`，可选 `instructions`，页数固定为六页。`revisionRequest` 是调用方预先指定的一次显式改进，用于验证同一制作子任务的新执行轮次；该轮单独计入 `acceptanceExerciseRevisions`，至多一次，不占 `maxRevisionRounds` 的质量修订预算，也不能记为真实质量缺陷。项目只读，合同和执行证据只写任务目录，只有八份产物进入公开目录。

固定流程：项目总结和六页脚本子任务 → 制作子任务 → 代码确定性校验 → 独立会话复核子任务 → 有限返工或交付。阶段间结束 ACP 对话轮次不改变父任务 `working`，等待阶段用 `waiting_children` 表达。制作返工在同一子任务继续并新建执行轮次，每次制作输出隔离到新版本；独立复核始终是另一个子任务。父任务执行轮次不因此增加。

机器校验实际检查严格八项 manifest、私有/公开/HTTP GET 字节、ZIP 完整性、六页 16:9、各页原生形状和可编辑文字、PNG 签名，以及与最终字节一致的实际 finalizer 原始回执。它不证明文字事实或视觉质量。独立复核必须自己查看总览和全部六页大图，核对脚本与源码，将事实与视觉结果绑定到清单摘要；制作自评不替代独立复核。发布前再读一次产物并校验摘要，检查项目基线与脚本来源未变化。

派出任何模型子任务前，交付角色先写入临时 PNG，并通过合同采用的 `/artifacts/<jobId>/revision-N/<file>` 路由真实 GET 比较字节，再移除探针并记录 `publication-preflight.json`。本目录的产物服务同时支持旧的两段地址与该三段版本地址；不开放任意嵌套目录，并逐级拒绝符号链接。必须同步部署此产物服务源码，仅更新网关不能证明版本链接可用。发布端 HTTP 404、超时或下载字节不符转为 `input_required`，不能消耗内容修订预算、让制作模型反复导出相同内容。修复前置条件后可按新任务显式关联 `replacesJobRef` 重测；本版本不自动重开已经终态的交付父任务。

协调状态中的 `pending` 在提交前持久化，客户端编号稳定。已知终态失败才能有限恢复；未知受理立即停止新派单等待核对。断连只推迟查询，不能证明停止。时长耗尽保留在途状态，不假称取消。不更改宿主全局模型或其他目标。父任务完成不等待通知 ack 或人工接受。`parentUpdatePending` 用于崩溃后补记父结果和通知；后台必须同时恢复 `working` 或有该待处理项的协调运行，通知按父任务执行轮次/结果版本幂等投递。

对因旧策略停止、但已取得独立验收 `passed` 的失败父任务，可显式启用目标的 `continue` 能力并以 `execution_continue`、`input: {}` 恢复：同一父 Job 新建执行轮次，原失败轮次保持终态。只接受无在途/未知子任务的已通过停点，冻结输入、宿主与角色不变；沿用原工作目录，新写恢复合同，保留累计成本、质量预算及总时长预算。恢复后先重新检查源码快照、产物字节与原验收摘要，匹配才继续。既有子 Job 不改变创建时的 `parentAttemptId`，其复用另记在新父轮次的 `recovery` 中；新增独立复核子任务关联新父轮次。其他失败或等待输入的停点仍不能自动重开，需明确处理前置条件。

验收记录包括提交、继续、后台查询、子通知 ack、机器校验次数、独立复核轮数、质量返工与显式演练轮数、累计耗时。模型 token/费用在后端不提供可靠数据时写 `unknown`，不能用主会话步骤减少推导总成本下降。主会话步骤数应从真实会话工具调用记录统计，区分开发部署成本与服务已就绪后的派单—回执—接受—ack 成本。

测试：在 `packages/service` 下运行 `node --import tsx --test test/ppt-delivery.test.ts`。
