## 保留的结论与后续边界

1. 主会话 3—5 次目标尚未达到。本次首次派单至最终验收审计为 38 次工具调用，含两次故障修复；首次实现、部署和准备另计 72 次。成功通知后的四次收尾不能当作整链达标证明。
2. 后续可做服务稳定就绪后的独立完整测量；本阶段不再追加制作或新测试任务，也不安排定时任务。
3. 宿主重启后的就绪判断仍需等待 Agent Card 与目标健康探测；显式探测对缓存结果的刷新语义可继续完善。
4. `reviewRounds=6` 包含恢复时重读已通过停点；实际独立验收会话为五个。审计以 Job/Attempt/sessionId 去重统计，后续可进一步统一指标口径。
5. workflow 目标可登记但执行 provider、通用 DAG 和 AP 投影不属于本阶段实现。PPT 的原生应用打开及跨字体渲染兼容性未验证；非阻断的排版、讲稿和记录问题保留在验收证据中。
